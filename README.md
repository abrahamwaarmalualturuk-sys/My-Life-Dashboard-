# My Life Dashboard

A responsive personal productivity dashboard for planning, tracking and managing university, career, organisations, business, programming, finances and personal development.

## Features
- Dashboard and daily overview
- Tasks, goals, projects and deadlines
- Notes and document tracking
- Areas for University, Career, SSYDIO, KUOY AGRISOL LTD and more
- Search
- Responsive mobile/desktop UI
- Local browser persistence
- JSON data export
- No backend required for the initial MVP

## Run
Open `index.html` in a browser.

## GitHub Pages
Enable Pages for the repository from **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`.
